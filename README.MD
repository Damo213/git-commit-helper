## 📖 简介

**Git 提交助手** 是一款 Git 图形化管理工具，专为不习惯命令行的开发者设计。它集成了 Git 日常操作的常用功能，并提供友好的可视化界面，让你一键完成代码提交、推送、标签管理等操作。

无需安装 Python，无需记忆 Git 命令，下载即可使用。

---

## ✨ 功能一览

| 功能模块       | 功能          | 说明                                     |
| -------------- | ------------- | ---------------------------------------- |
| **仓库管理**   | 选择/切换仓库 | 支持浏览选择、最近仓库快速切换           |

|                | 🚀 首次推送    | 一键执行 `git push -u origin main`       |

## 🚀 快速开始

### 1. 下载程序
从 Releases 页面下载 `GitCommitHelper.exe`。

### 2. 运行程序
双击 `GitCommitHelper.exe` 即可启动。

### 3. 选择仓库
- 首次运行会弹出选择目录对话框。
- 选择你的 Git 项目目录（或普通文件夹，程序会自动询问是否初始化 Git）。
- 也可以随时点击 **“📂 选择仓库”** 切换目录。

### 4. 设置远程（首次使用）
- 在 **“远程地址”** 输入框中粘贴你的仓库 URL（如 `https://github.com/用户名/仓库名.git`）。
- 点击 **“🔗 设置远程”** 完成绑定。
- 点击 **“🚀 推送 (首次)”** 完成首次推送。

### 5. 开始使用
- 勾选文件 → 填写提交信息 → 点击 **“✅ 提交”**。
- 日常推送点击 **“🚀 推送”** 即可。

## 🐛 常见问题

### Q：打开程序提示“不是有效的 Git 仓库”？
**A**：选择目录后，程序会自动询问是否执行 `git init`，点击“是”即可初始化。

### Q：如何重置配置？
**A**：删除程序所在目录下的 `git_commit_config.json` 文件，重新运行程序即可。

### Q：首次推送失败？
**A**：请确认：
1. 已设置远程地址（输入框中填写了 URL）
2. 至少有一次本地提交记录
3. 网络连接正常
4. 有仓库的推送权限

### Q：备份目录越来越大怎么办？
**A**：可以定期清理 `backup/` 目录下旧的备份文件夹，只保留最近几个版本。

### Q：程序被 Windows Defender 拦截？
**A**：个人开发者发布的 exe 可能被误报，点击“仍要运行”即可。如不放心，可自行审查源码后打包。
