## 📖 项目简介

**Git 提交助手** 是一个基于 Python + CustomTkinter 开发的 Git 图形化管理工具，专为不习惯命令行的开发者设计。它集成了 Git 日常操作的常用功能，并提供了友好的可视化界面。

无论你是想快速提交代码、管理标签，还是设置远程仓库，都可以在这个工具中一键完成。

## ✨ 功能总览

| 功能模块 | 具体功能 | 说明 |
|----------|----------|------|
| **仓库管理** | 选择/切换仓库 | 支持浏览选择、最近仓库快速切换 |

| | 远程地址管理 | 主界面直接输入/设置远程仓库 URL |

| | 🚀 推送 (push) | 推送到远程仓库 |
| | 🚀 首次推送 (push -u) | 一键执行 `git push -u origin main` |

| | 🔄 切换标签 | 快速切换到指定标签 |

## 📋 详细使用指南

### 一、仓库管理

#### 选择仓库

- 点击 **“📂 选择仓库”** 浏览并选择 Git 仓库目录。
- 点击 **“📋 最近”** 快速切换到最近使用过的仓库。

#### 初始化仓库

- 如果选择的目录不是 Git 仓库，程序会自动弹窗询问是否执行 `git init`。
- 点击“是”即可一键初始化。

### 二、远程管理（新增）

#### 设置远程地址

1. 在 **“远程地址”** 输入框中粘贴你的仓库 URL（如 `https://github.com/用户名/仓库名.git`）。
2. 点击 **“🔗 设置远程”**，自动执行 `git remote add origin <URL>`。

#### 首次推送

- 设置好远程地址后，点击 **“🚀 推送 (首次)”**，自动执行 `git push -u origin main`。
- 后续日常推送只需点击普通 **“🚀 推送”** 按钮即可。

### 三、提交与同步

#### 提交代码

1. 在文件列表中勾选要提交的文件。
2. 在 **“提交信息”** 输入框中填写说明。
3. 点击 **“✅ 提交”**。
4. 提交成功后会自动备份项目到 `backup/` 目录。

#### 推送与拉取

- **“🚀 推送”**：将本地提交推送到远程仓库。
- **“📥 拉取”**：从远程仓库拉取最新代码。

### 四、标签管理

#### 创建标签

1. 在 **“标签名”** 输入框中填写版本号（如 `v1.0.0`）。
2. 在 **“标签信息”** 输入框中填写版本说明。
3. 点击 **“🏷️ 创建标签”**。
4. 弹窗询问是否推送标签，点击“是”则同步推送到远程。

#### 快速选择

- 点击标签列表中的标签按钮，可快速填入名称到输入框。

### 五、构建与备份

- **“🔨 构建项目”**：调用项目根目录的 `build.py` 打包 exe。
- **“💾 备份项目”**：手动备份整个项目（自动排除 `.git`、`logs`、`backup` 等目录）。

## ⚠️ 注意事项

1. **Git 环境**：确保系统已安装 Git 且 `git` 命令可用。

   bash

   ```
   git --version
   ```

## 🐛 常见问题

### Q：提示“不是有效的 Git 仓库”？

A：请确保选择的目录是 Git 仓库（存在 `.git` 文件夹），或点击“是”让程序自动初始化。

### Q：如何重置配置？

A：删除项目根目录下的 `git_commit_config.json` 文件，重新运行程序即可。

### Q：远程地址设置失败？

A：检查 URL 格式是否正确（如 `https://github.com/用户名/仓库名.git`），并确保有网络权限。

### Q：首次推送失败？

A：确保已设置远程地址，且本地已有至少一次提交记录。

### Q：日志文件在哪里？

A：在项目根目录下的 `logs/` 文件夹中，按日期命名。
