# 📦 Git 提交助手 · 完整版

> 一个带 GUI 的 Git 管理工具，集成提交、推送、拉取、标签管理、项目构建、自动备份、日志记录于一体。

---

## ✨ 功能总览

| 功能 | 说明 |
|------|------|
| ✅ 提交 (commit) | 勾选文件 → 填写信息 → 一键提交 |
| 🚀 推送 (push) | 推送到远程仓库 |
| 📥 拉取 (pull) | 从远程拉取最新更新 |
| 📡 查看远程 | 查看远程分支、本地与远程的差异提交 |
| 🏷️ 标签管理 | 创建/切换/删除带注释的标签，支持推送 |
| 🔨 构建项目 | 调用 `build.py` 打包 exe |
| 💾 自动备份 | 每次提交成功后自动备份整个项目 |
| 📋 日志保存 | 所有操作日志自动保存到 `logs/` 目录 |
| 🧹 自动忽略 | 工具自身自动加入 `.gitignore` |

---

## 🚀 快速开始

### 1. 运行工具

在项目根目录下执行：

​```bash
python git_commit_gui.py
```



或直接双击文件运行（Windows）。

### 2. 选择仓库

- 工具启动后默认使用当前目录作为 Git 仓库路径
- 点击 **“📂 浏览”** 可切换到其他 Git 仓库目录
- 点击 **“🔄 刷新”** 重新扫描文件变更

### 3. 提交代码

1. 在文件列表中勾选要提交的文件（支持双击文件名快速暂存/取消暂存）
2. 在 **“提交信息”** 输入框中填写说明
3. 点击 **“✅ 提交”** 完成提交
4. 提交成功后会自动备份整个项目

### 4. 推送代码

点击 **“🚀 推送”** 将本地提交推送到远程仓库。

### 5. 拉取更新

点击 **“📥 拉取 (pull)”** 从远程仓库拉取最新代码。

### 6. 查看远程信息

点击 **“📡 查看远程”**，工具会：

- 执行 `git fetch` 获取最新远程信息
- 显示远程分支列表
- 显示本地与远程的差异提交（落后/领先）

### 7. 标签管理

**创建标签：**

1. 在 **“标签名”** 输入框中填写版本号（如 `v1.0.0`）
2. 在 **“标签信息”** 输入框中填写版本说明
3. 点击 **“🏷️ 创建标签”**
4. 弹出是否推送标签的确认框，点击“是”则同步推送到远程

**切换标签：**

1. 在 **“标签名”** 输入框中填写已存在的标签名
2. 点击 **“🔄 切换标签”** 即可切换到该标签（detached HEAD 状态）

**删除标签：**

1. 在 **“标签名”** 输入框中填写要删除的标签名
2. 点击 **“🗑️ 删除标签”** 确认后，本地和远程标签同时删除

**快速选择：**

- 点击标签列表中的标签按钮，可快速填入标签名到输入框

### 8. 构建项目

点击 **“🔨 构建项目”**，工具会调用 `build.py` 脚本打包 exe，构建过程日志实时显示。

### 9. 备份项目

- **自动备份**：每次 `commit` 成功后自动备份
- **手动备份**：点击 **“💾 备份项目”** 随时备份

备份规则：

- 备份到 `backup/backup_时间戳/` 目录
- 自动排除 `.git`、`logs`、`backup`、`dist`、`build`、`__pycache__` 等目录
- 自动排除 `.gitignore` 中声明的文件

## 📋 日志文件

- 所有操作日志自动保存到 `logs/git_commit_YYYYMMDD.log`
- 日志格式：`[时间] [级别] 消息内容`
- 界面右上角的 **“🗑️ 清空日志”** 只清空界面显示，不影响已保存的日志文件

## ⚠️ 注意事项

1. **Git 环境**：确保系统已安装 Git 且 `git` 命令可用（在命令行输入 `git --version` 验证）

2. **Python 环境**：需要 Python 3.8+，并安装 `customtkinter`：

   bash

   ```
   pip install customtkinter
   ```

   

3. **构建功能**：需要项目根目录存在 `build.py` 脚本

4. **标签切换**：切换到标签后会进入 detached HEAD 状态，如需继续开发请切回分支

5. **备份排除**：`backup` 目录本身不会被备份，避免无限递归

------

## 🧹 自动忽略

工具启动时会自动检测 `.gitignore`，如果其中没有 `git_commit_gui.py`，会自动添加一行，确保该工具不会被提交到仓库。

## 📝 常见问题

### Q：提示“不是有效的 Git 仓库”？

A：请确保选择的目录是 Git 仓库（存在 `.git` 文件夹），或先执行 `git init` 初始化。

### Q：备份时提示权限错误？

A：请确保项目目录下的文件没有被其他程序占用（如编辑器打开中）。

### Q：标签创建失败？

A：检查标签名是否已存在，或是否包含特殊字符。

### Q：日志文件在哪里？

A：在项目根目录下的 `logs/` 文件夹中，按日期命名。
